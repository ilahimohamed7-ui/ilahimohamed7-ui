## Projekte

### 1. KI-Telefonagent

**Einzelprojekt · Python · FastAPI · Supabase · SQL · Retell AI**

Ich habe einen Demo KI-Telefonagenten entwickelt, der am Beispiel eines Friseursalons eingehende Anrufe entgegennimmt und mit Anrufern über Terminwünsche spricht.

Über Supabase ist der Agent mit einer SQL-Datenbank verbunden. Er kann die Verfügbarkeit von Terminen prüfen und Termine hinzufügen oder absagen.

**Technische Schwerpunkte:**
- Anbindung eines KI-Telefonagenten an ein Backend
- Kommunikation mit einer SQL-Datenbank
- Abfrage und Verarbeitung von Termindaten
- Automatisierte Unterstützung bei der Terminverwaltung

[Repository auf GitHub ansehen](https://github.com/ilahimohamed7-ui/ki-telefonagent)

### 2. KI-E-Mail-Agent

**Teamprojekt · Python · KI-Integration · E-Mail- und Kalenderanbindung**

Gemeinsam mit einem Kollegen habe ich einen KI-E-Mail-Agenten entwickelt, der E-Mails einliest, zusammenfasst und Antwortvorschläge erstellt. Außerdem erkennt er Termine in E-Mails und kann diese in einen Kalender eintragen.

**Technische Schwerpunkte:**
- Verarbeitung und Analyse von E-Mail-Inhalten
- KI-gestützte Zusammenfassungen und Antwortentwürfe
- Erkennung von Termininformationen
- Verbindung von E-Mail- und Kalenderfunktionen

Der vollständige Quellcode bleibt privat. Eine öffentliche Projektbeschreibung und eine Demo können separat bereitgestellt werden.

**Technische Schwerpunkte:**
